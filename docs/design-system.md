# parallexity — дизайн-система 1.0

Статус: общая спецификация и тема существующего веб-пульта. Подробный разбор Apple: [apple-analysis.md](design/apple-analysis.md). Новые функции «Окна» и «Избранное» ещё не реализованы. Этот документ определяет их оформление и дальнейшую переработку существующих экранов.

В 0.10.0 оформлено и приложение Windows: `DesktopTheme.cs` задаёт цвета и радиусы, `RoundedCard` и `RoundedButton` используют их с учётом DPI. Это адаптация для WinForms с плотными поверхностями, а не имитация оптического преломления. Переключатели остаются переключателями с движущимся бегунком; запрет круглых кнопок относится к кнопкам действий. Визуальный результат: `design/desktop-0.10.0.png`.

## Направление

Интерфейс в духе Liquid Glass iOS 26–27: ясная иерархия, полупрозрачные элементы управления, плавающая навигация, сгруппированные списки. Собственная графитовая палитра parallexity. Без круглых кнопок, цветных логотипов, радужных бликов и лишней анимации. Референс: `design/parallexity-1.0-liquid-glass.png`.

Стекло применяется преимущественно к навигации, выбору источника, избранному и кнопкам. Длинные списки и карточки текста имеют более плотный графитовый фон. Материал: мягкое размытие 24 px, тонкая светлая граница и внутренний верхний блик. Спокойная серебристая подложка допускается для глубины; текст остаётся контрастным. Нельзя делать яркую светящуюся рамку у каждой строки. При отсутствии backdrop-filter и запросе reduced-transparency используется непрозрачная поверхность. Не анимировать размытие и не отслеживать каждый жест ради световых эффектов.

Это веб-адаптация визуального языка, а не использование нативного материала Apple. CSS не воспроизводит физическое преломление Liquid Glass. Официальные ориентиры: [iOS 26](https://support.apple.com/en-us/123075), [iOS 27](https://www.apple.com/os/ios/?os=app).

## Токены

Источник значений: `../web/design-tokens.css`. Все новые компоненты используют эти переменные. Изменения палитры, размеров и скруглений вносятся туда, а не отдельными значениями в компоненты. Тема существующего пульта подключает токены через apple-theme.css.

| Назначение | Значение |
| --- | --- |
| Фон / карточка / вложенная поверхность | #000000 / #1C1C1E / #2C2C2E |
| Основной / вторичный текст | #FFFFFF / #AEAEB8 |
| Акцент | белый фон, тёмный текст |
| Базовый шаг отступов | 4 px |
| Поля экрана / карточки / промежуток секций | 20 / 16 / 24 px |
| Скругление карточки / кнопки / значка | 24 / 16 / 10 px |
| Заголовок экрана / секции / основной текст / подпись | 34 / 22 / 17 / 13 px |
| Минимальная область касания | 48 × 48 px |

Шрифт: system-ui, -apple-system, BlinkMacSystemFont, Segoe UI, sans-serif. На iPhone используется системный шрифт; отдельные файлы шрифтов не загружаются. Подпись не меньше 12 px; поля ввода — минимум 16 px. Заголовки имеют умеренную насыщенность 650; основной текст — 400–500. Не использовать прописные разреженные надписи вместо обычных заголовков.

## Компоненты

- Кнопка: скруглённый прямоугольник, высота от 48 px. Основная — светлая; вторичная — графитовая. Кнопка только со значком тоже прямоугольная, с доступным названием.
- Избранное: сетка в две колонки, значок и подпись. Плитка запускает заранее настроенное приложение или ссылку; не меняет выбранный плеер.
- Открытые окна: одна карточка с разделителями между строками. В строке значок, название приложения, заголовок окна и стрелка. Нажатие показывает окно на мониторе; воспроизведение не запускается.
- Быстрые действия: широкие строки «Погасить экран» и «Таймер», без круглых значков-кнопок.
- Транспорт плеера: три прямоугольные кнопки, центральная светлая. Не использовать круг даже для воспроизведения. Громкость остаётся ползунком; его бегунок допустим круглым, это не отдельная кнопка.
- Нижняя навигация: четыре равных пункта «ПК», «Медиа», «Звук», «Управление». Активный пункт — скруглённый прямоугольник. Safe area учитывается отдельно от высоты панели.
- Диалог: нижняя панель на телефоне, обычный диалог на широком экране. Заголовок, прямоугольная кнопка закрытия, один понятный основной шаг. Для выбора приложений настройка производится на ПК; телефон запускает сохранённые записи.
- Техническая диагностика скрыта в раскрываемом блоке; ошибки подключения видны рядом с соответствующей функцией.

## Состояния и поведение

У каждого действия есть состояния: обычное, нажатое, клавиатурный фокус, выполнение, недоступно, ошибка. Нажатие слегка меняет фон; анимация 140 ms. При prefers-reduced-motion анимация отключается. Во время команды повторная отправка блокируется; успех и отказ показываются текстом. Активность не обозначается только цветом. Фокус имеет отчётливую обводку. Ошибка не скрывается таймером до того, как пользователь сможет её прочитать.

Список окон не смешивается со списком видеовкладок и плееров Windows. Если выбранный плеер недоступен, команды не отправляются другому плееру автоматически. Системный запрет вывести окно на передний план показывается как отказ, а не как успех.

## Адаптивность

Целевая ширина телефона: 320–480 px. Нет горизонтального скролла страницы; длинные названия обрезаются в списке, полное название доступно в деталях. Текстовые элементы имеют min-width: 0; элементы управления не сжимаются ниже минимального размера. Прокрутка списка сохраняется. На широком экране содержимое ограничено по ширине и выровнено по сетке.

Запрос пользователя — исключить случайное масштабирование жестами. Существующее ограничение viewport и touch-action сохраняется; оно не считается гарантией поведения Safari. Проверять на настоящем iPhone отдельно, вместе с фокусом ввода, прокруткой и жестами тачпада.

## Проверка перед выпуском

Проверить 320, 393 и 480 px; длинные названия; пустые списки; загрузку, отказ и потерю связи; управление с клавиатуры; отсутствие круглых кнопок; соответствие токенам. Генерированный референс показывает визуальное направление и не подтверждает готовность функций.
