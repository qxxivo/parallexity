# Проверка parallexity 0.4.0

Дата: 11 октября 2026.

- Локальная сборка Release выполнена без предупреждений компилятора.
- 69 автоматических проверок пройдены; ещё три записи отчёта описывают реальное устройство вывода, медиасессии и аудиосессии Windows.
- Сохранены проверки сопряжения, CSP, Host/Origin, одноразового QR, отказа ПК, сохранения и отзыва доверия, валидации команд, Unicode, Win32 INPUT и обновлений GitHub.
- Перетаскивание проверено на имитации ввода: раздельные mouse-down и mouse-up, ограниченный идентификатор жеста, запрет перехвата другим телефоном и вмешательства кликом, обновление срока удержания, отпускание по таймауту, отзыв разрешения и завершение сервера. Просроченные движения не возобновляют удержание. Команды проходят через сопряжённый HTTP-клиент.
- Windows ICO загружается из встроенного ресурса без ошибок.
- В браузере проверены сопряжение, пауза, микшер, отправка русского текста с emoji, раскрытие блока клавиатуры, обычное движение и удержание тачпада. Журнал имитации подтвердил drag-start, heartbeat drag-move и drag-end при отпускании.
- Итоговая графитовая вёрстка проверена на 393 и 320 пикселях без горизонтального переполнения. В проверенных сценариях ошибок и предупреждений JavaScript не обнаружено.
- Реальные громкость, воспроизведение, мышь и клавиатура в автоматических проверках не менялись. Плавность и перетаскивание в конкретных окнах требуют проверки с реальным телефоном.
- Установленная пользовательская версия 0.3.0 не заменялась; 0.4.0 предназначена для самостоятельной установки кнопкой обновления.

В версии 0.3.0 отдельно проверены настоящее скачивание EXE из GitHub Releases, его SHA-256 и установка с сохранением файла подключённых устройств. Источником доверия обновления служит репозиторий GitHub, а не отдельная подпись издателя. Независимый аудит безопасности не проводился.
