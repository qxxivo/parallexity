# Проверка parallexity 0.9.3

В 0.9.3 проверены передача диагностики через backend, версия расширения, подсчёт ответивших и недоступных областей страницы, сохранение результата неудачного подключения и отображение ошибки последней команды. Протокол принимает только ограниченные счётчики и известные состояния; адреса страниц, токены и текст исключений Chrome не передаются. Совместимость реального Кинопоиска пока не подтверждена.

В 0.9.2 тест Chrome API доставляет событие изменения выбранной вкладки после начала внедрения скриптов: подключение сохраняется, подтверждается выбранный номер и доступны команды. Тест интерфейса воспроизводит неудачный выбор «Кинопоиск», когда текущий браузерный и Windows-плеер — YouTube: заголовок остаётся «Кинопоиск», кнопки блокируются и ни одна команда транспорта не отправляется другому плееру. Возврат к Windows разрешается только после явного отключения. Backend проверяет номер вкладки для воспроизведения. Эти проверки используют имитацию; реальная совместимость Кинопоиска пока не подтверждена.

В 0.9.1 автоматические сценарии интерфейса проверяют появление браузера без медиа-сессий Windows, открытие списка вкладок из выбора плеера, отсутствие команды воспроизведения при открытии списка, доступность других плееров при выбранной вкладке, явное отключение вкладки при переходе к приложению и удаление пункта браузера при потере подключения расширения. Это исправление доступности выбора; совместимость реального плеера Кинопоиска этим тестом не подтверждается.

Дата: 11 октября 2026.

В 0.9.0 прошли 153 проверки backend и четыре набора Node-сценариев. Проверены диапазон громкости, обязательное состояние выключенного звука, принадлежность последней вкладки текущему каталогу, передача уровня через content.js и подтверждение команды. Команда привязана к вкладке; изменение выбора во время жеста или обработки отклоняет перенос команды на другой плеер. Проверены запоминание открытого плеера после отключения, удаление закрытой вкладки из возврата и очистка номера при старте браузера. Сам player.js проверен на изменение громкости, отдельное выключение звука и сохранение состояния mute при движении ползунка. В настоящем браузере с имитацией вкладок и ПК проверены изменение ползунка с 65% до 64%, выключение звука видео, сохранение общего звука 42%, отключение вкладки и возврат к тому же плееру; журнал команд Windows пуст. Интерфейс проверен на ширинах 393 и 320 пикселей; реальное расширение в пользовательский Chrome не устанавливается. Совместимость конкретных сайтов пока не подтверждена.

В 0.8.2 прошли 142 проверки backend и четыре набора Node-сценариев. Проверено наличие всех необходимых файлов встроенного расширения в сборке. В коде расширения с имитацией Chrome API проверены подключение плеера при отказе одного встроенного фрейма и отказ от успешного подтверждения при полной ошибке внедрения. В настоящем коде страницы телефона проверена маршрутизация больших кнопок паузы и перемотки в выбранную вкладку. В тестовом браузерном интерфейсе с имитацией вкладок большая кнопка паузы меняет состояние выбранного видео. Реальный Chrome с расширением и конкретные сайты пользователя в этой проверке не использовались.

В 0.8.1 дополнительно проверены обновление фонового плеера без таймера самой страницы, очистка прежнего номера вкладки при старте браузера и настоящий content.js: проверка идентификатора страницы и отправителя, защита от двойной команды, немедленная отправка состояния при повторном выборе без второго таймера. Всего 134 проверки backend и четыре набора Node-сценариев. Проверка ограничений таймеров настоящего Chrome пока не выполнялась.

В 0.8.0 прошли 134 автоматические проверки backend и три набора Node-сценариев. Проверены ограниченный каталог вкладок, отсутствие полного адреса в поле домена, уникальные идентификаторы, выбор только вкладки из текущего списка, подтверждение нового выбора после смены поколения страницы и отклонение несовпадающего подтверждения. Настоящий HTTP API принимает каталог больше 4096 байт только в защищённом локальном канале расширения.

Исходный код расширения выполнен с имитацией Chrome API: выбор из каталога без текущего плеера, сортировка, отсутствие внутренних и инкогнито-страниц, отсутствие URL-параметров в сообщении, защита названия устаревшей инкогнито-вкладки, фокус без смены пульта, отключение, закрытая вкладка и выключенное согласие на список. Запоздавший ответ об отзыве старого токена не удаляет новое сопряжение.

В настоящем браузере с отдельной имитацией ПК и вкладок проверены окно выбора, поиск по названию, успешное переключение и закрытие списка, показ нового названия и отключение вкладки. Интерфейс просмотрен на ширинах 393 и 320 пикселей. Новое расширение в пользовательский Chrome/Edge не устанавливалось; реальное получение списка и запуск Chrome после завершения фонового процесса пока не проверялись. Все изменения рабочего приложения предназначены для кнопки обновления.

В 0.7.0 прошли 123 автоматических проверки backend и три набора Node-сценариев. Проверены авторизация, явное состояние режима просмотра, повторное включение без дублирования запросов, отказ Windows, отзыв доверия, освобождение запросов при завершении и отключение режима перед ручным выключением экрана и обоими действиями таймера. Проверка реального Windows API создала и сразу освободила запросы удержания ПК и экрана; ожидание физического таймаута сна не выполнялось.

Исходный код расширения проверен с имитацией Chrome API: переключение окна в fullscreen, выход с восстановлением maximized, фокус правильного окна, отказ от устаревшей команды при переходе страницы. Дополнительные разрешения не добавлялись. В пользовательский браузер расширение пока не устанавливалось; реальное переключение окна Chrome/Edge не проверялось.

В настоящем браузере с тестовым backend проверены включение режима просмотра, статус «Включён», выключение через «Погасить экран» и статус «Выключен». Интерфейс просмотрен на ширинах 393 и 320 пикселей. Команда выключения экрана имитировалась.

В 0.6.0 прошли 109 автоматических проверок backend и три набора Node-сценариев. Проверены запуск, отмена, точное однократное выполнение таймера и отзыв доверия его владельца; сопряжение расширения, срок и одноразовость кода, хранение только хеша токена на ПК, отзыв доступа и устаревание состояния вкладки. Настоящий локальный HTTP API проверен с имитацией управления ПК.

Node-сценарии выполняют исходный код расширения: обнаружение подписей, скрытых/отключённых кнопок, ожидания рекламы, границ перемотки; выбор вкладки и фрейма, подтверждение команды, смена страницы и вкладки, отключение. Исходный web/app.js проверен на показ доступных кнопок и маршрутизацию таймера (плеер, браузер, выключение экрана, отмена), дополнительно к прежним сценариям переподключения.

Расширение пока не установлено в пользовательский браузер. Работа на настоящих YouTube, Кинопоиске и сторонних сайтах не проверялась; универсальное обнаружение кнопок не гарантирует совместимость с каждым плеером. После разрешения пользователя в настоящем браузере на тестовом localhost проверены подключение, запуск таймера выключения экрана, обратный отсчёт и отмена. Интерфейс таймера просмотрен на ширине 393 пикселя; команды имитировались, настоящий экран не выключался. Перечисленные ниже дополнительные проверки интерфейса относятся к ранее выпущенной версии.

В 0.5.1: Node-сценарии проверяли восстановление раздела и точного режима, запись изменений, повреждённую настройку и недоступное хранилище браузера. В настоящем браузере после reload проверены «Управление», включённый точный режим и сохранённое сопряжение. Обновление адресов сети и сохранение выбранного устройства проверены по коду и сборкой; физическое переключение роутера/VPN не выполнялось.

- Release и 87 записей автоматических проверок: подключение, обновления, управление, очистка, единственный экземпляр и сохранение устройств.
- Новая display-off проверена через настоящий HTTP API с FakeControls: без сопряжения недоступна, другой Origin блокируется, у доверенного телефона не требует разрешения мыши/клавиатуры. Команда sleep не поддерживается.
- Node-сценарии переподключения выполняют настоящий web/app.js: обрыв, восстановление, скрытие страницы, отмена старого запроса, отзыв доверия и проверка ссылки подключения.
- Страница проверена в браузере на ширинах 393 и 320 пикселей. Проверены медиапульт, управление и нажатие кнопки display-off; журнал тестового backend подтвердил получение команды.
- Окно Windows проверено отдельным --design-preview: тестовые подключения и имитация команд, без изменения данных рабочего пульта и автозапуска.
- Выключение реального монитора во время работы пользователя не выполнялось. Используется Windows WM_SYSCOMMAND/SC_MONITORPOWER, без команд сна и завершения работы. Настройки автосна Windows сохраняются. Поведение на физическом устройстве зависит от драйвера и схемы питания.
- Установленное приложение пользователя не заменяется: выпуск предназначен для кнопки обновления. Размер самостоятельного сжатого EXE остаётся около 89 МБ.
