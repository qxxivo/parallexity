# Проверка parallexity 0.3.0

Дата: 11 октября 2026.

- Сборка Release: успешно, без предупреждений компилятора.
- 51 автоматическая проверка выполнена успешно; ещё три записи отчёта описывают доступность реального устройства вывода, медиасессий и аудиосессий Windows.
- Проверяются встроенная страница, CSP, доступ без сопряжения, Host и Origin, отказ ПК, одноразовый QR, валидация команд, сохранение и отзыв доверия, отдельное разрешение ввода, Unicode, Win32 INPUT и отпускание модификаторов.
- Проверки обновлений: стабильная версия, запрет стороннего источника/репозитория, обязательный SHA-256, предел размера, несовпадение размера/хэша, замена EXE, сохранение предыдущей сборки и данных, сохранение установленного файла при ошибке копирования.
- В автоматических проверках реальная громкость, воспроизведение, мышь и клавиатура не изменяются. Замена EXE проверяется на отдельных временных файлах.
- Для предшествующей версии 0.2 проверена мобильная вёрстка на 393 и 320 пикселях без горизонтального переполнения и сценарии с имитацией ПК: сопряжение, вкладки, микшер, русский текст с emoji, клики, прокрутка, точный режим. JavaScript-ошибок в этом сценарии не обнаружено.

Версию 0.1 пользователь подтвердил как работающую с телефона. Новые функции требуют проверки на конкретном телефоне и в конкретных окнах ПК. Это прототип; независимый аудит безопасности не проводился. Проверка SHA-256 обновления использует метаданные GitHub, а не отдельную подпись издателя.
