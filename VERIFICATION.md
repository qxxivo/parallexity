# Проверка parallexity 0.4.1

Дата: 11 октября 2026.

- Изменение выпуска: утверждённый логотип двух связанных экранов в мобильном интерфейсе, заголовке окна Windows, значке EXE и меню возле часов.
- Канонический источник — assets/logo.svg. scripts/build-logo.ps1 создаёт SVG для браузера и ICO из одной геометрии; ICO включает размеры 16, 20, 24, 32, 48, 64, 128 и 256 пикселей.
- Локальная сборка Release и 69 автоматических проверок выполнены успешно. Загрузка встроенного Windows ICO проверяется настоящим декодером System.Drawing.Icon.
- Установленный пульт пользователя не заменяется; выпуск предназначен для установки через кнопку обновления.

В выпуске 0.4.0 проверены мобильные экраны 393 и 320 пикселей, медиакнопки, микшер, текст, движение, удержание и отпускание тачпада. В выпуске 0.3.0 проверены реальное скачивание из GitHub Releases, SHA-256 и установка с сохранением данных устройств. Функциональность управления в 0.4.1 не изменяется. Независимый аудит безопасности не проводился.
