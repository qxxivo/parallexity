# Проверка parallexity 0.4.3

Дата: 11 октября 2026.

- Локальная сборка Release без ошибок и предупреждений; 83 записи проверок завершились успешно. Готовый самостоятельный сжатый EXE также прошёл проверки; размер около 89 МБ.
- Два экземпляра с одинаковым именем Windows mutex проверены на разных потоках: второй не получает владение и передаёт событие открытия окна. После закрытия первого новый экземпляр получает владение.
- Команда автозапуска корректно заключает путь с пробелами в кавычки и передаёт --startup. Тесты не включают автозапуск в системе пользователя.
- Node-сценарии выполняют настоящий web/app.js с управляемой сетью: обрыв связи, ограниченное увеличение интервала повторов, восстановление сети, скрытие страницы, отмена зависшего запроса при возвращении, отзыв подключения и проверка ссылки сопряжения. При переподключении управляющие команды не воспроизводятся.
- Через настоящий HTTP-сервер проверены manifest, чистый start_url без токенов и PNG-значки размером 180, 192 и 512 пикселей.
- В браузере проверены подключение тестового телефона и раскрытие инструкции главного экрана; используются имитации управления, без действий на рабочем столе пользователя.
- GitHub Actions дополнительно выполняет серверные проверки и сценарии переподключения перед публикацией релиза.

Ограничения: проверка на физических Android/iPhone и реальный вход в Windows после включения автозапуска ещё не выполнены. В локальном HTTP браузер может создавать ярлык вместо отдельного веб-приложения; отдельное окно может потребовать новое сопряжение. При смене IP-адреса ПК нужен новый QR-код. Независимый аудит безопасности не проводился.

Установленный пульт пользователя не заменяется: выпуск устанавливается через кнопку обновления.
