# parallexity · плеер браузера

Бесплатное расширение для Chrome, Edge и других браузеров на Chromium. Нужен parallexity 0.6.0 или новее на этом же ПК.

1. Распакуй `parallexity-browser.zip` в отдельную постоянную папку.
2. Открой страницу расширений браузера (`chrome://extensions` или `edge://extensions`), включи режим разработчика, нажми «Загрузить распакованное» и выбери папку с manifest.json.
3. Открой меню значка parallexity рядом с часами → «Расширение браузера…». Скопируй код и вставь в окно расширения. Код действует две минуты; подключение сохраняется после перезапуска ПК.
4. Открой вкладку с видео, нажми расширение → «Управлять этой вкладкой», разреши доступ к сайтам. Разрешение нужно для плееров во вложенных фреймах; код запускается только в выбранной вкладке. Для другой вкладки повтори этот шаг.
5. На телефоне в разделе «Медиа» появятся доступные действия.

Расширение ищет видимый HTML-видеоплеер и кнопки «Пропустить заставку», «Пропустить рекламу», «Следующая серия», включая английские подписи. Есть отдельное распознавание кнопки пропуска YouTube. Оно нажимает существующую доступную кнопку; рекламу не блокирует и платный доступ не обходит. Поддержка каждого сайта не гарантируется. Защищённые и нестандартные плееры могут потребовать отдельной настройки.

Связь с приложением идёт через 127.0.0.1. Во внешние сервисы данные не отправляются. Передаются название выбранной вкладки, доступные действия и результат команды. История, пароли и содержимое полей не собираются. Телефоном может управлять только устройство, подтверждённое на ПК. В меню ПК можно отозвать доступ расширения; кнопка «Отключить вкладку» прекращает управление вкладкой.

Обновление распакованного расширения: скачай новый ZIP, закрой браузер, замени файлы в его папке, запусти браузер и нажми «Обновить» на карточке расширения. Кнопка обновления приложения ПК обновляет только приложение.
