# parallexity · плеер браузера

Бесплатное расширение для Chrome 120+, Edge и совместимых браузеров на Chromium. Нужен parallexity 0.9.0 или новее на этом же ПК.

1. В меню значка parallexity рядом с часами открой «Расширение браузера…» → «Подготовить расширение». Папка откроется, а её путь будет скопирован. Скачивать и распаковывать ZIP больше не нужно.
2. Открой страницу расширений браузера (`chrome://extensions` или `edge://extensions`), включи режим разработчика, нажми «Загрузить распакованное» и выбери папку с manifest.json.
3. Открой меню значка parallexity рядом с часами → «Расширение браузера…». Скопируй код и вставь в окно расширения. Код действует две минуты; подключение сохраняется после перезапуска ПК.
4. Нажми «Подключить и разрешить управление» и разреши доступ к сайтам. В пульт передаются названия и домены обычных открытых вкладок этого профиля, а также признак звучащего аудио. По умолчанию эта возможность выключена. История, поле адреса вкладки и вкладки инкогнито не передаются. Доступ к сайтам также нужен для плееров во вложенных фреймах; код управления плеером запускается только в выбранной вкладке.
5. На телефоне открой «Медиа» → «Выбрать вкладку». Есть поиск и отметка «Со звуком». Нажми название для подключения к пульту; «На ПК» выведет страницу на передний план. Список обновляется автоматически, максимум 200 вкладок. Выбор не включает воспроизведение автоматически.

«Выбрать текущую вкладку» в расширении по-прежнему позволяет подключить одну страницу напрямую. «Отключить управление» в расширении прекращает передачу списка и управление; «Отключить» на телефоне отключает только выбранную вкладку, оставляя возможность выбрать следующую.

Расширение ищет видимый HTML-видеоплеер и кнопки «Пропустить заставку», «Пропустить рекламу», «Следующая серия», включая английские подписи. Есть отдельное распознавание кнопки пропуска YouTube. Оно нажимает существующую доступную кнопку; рекламу не блокирует и платный доступ не обходит. Поддержка каждого сайта не гарантируется. Защищённые и нестандартные плееры могут потребовать отдельной настройки.

Громкость видео и выключение звука доступны в основном плеере телефона при обнаружении HTML-видеоплеера. Изменяется громкость самого видео; общий звук Windows и других приложений не затрагивается. Изменение ползунка сохраняет выбранное состояние выключенного звука.

«Вернуться к просмотру» подключает последнюю вкладку с видео после её отключения от пульта, если вкладка всё ещё открыта. Воспроизведение не запускается автоматически. Хранится только номер вкладки в памяти текущей сессии расширения; после перезапуска браузера, обновления или перезагрузки расширения он очищается. Полное отключение управления также очищает возврат.

«Полный экран окна» разворачивает окно выбранной вкладки браузера. Вкладка становится активной, её окно выходит на передний план. «Выйти из полного экрана» возвращает прежний обычный или развёрнутый размер. Собственный полноэкранный режим видео остаётся функцией сайта. Дополнительные разрешения расширения для управления окном не добавлены.

Связь с приложением идёт через 127.0.0.1. Во внешние сервисы данные не отправляются. Передаются названия и домены разрешённых вкладок, доступные действия и результат команды; на ПК список находится только в памяти. История, пароли и содержимое полей не собираются. Управлять может только телефон, подтверждённый на ПК. В меню ПК можно отозвать доступ расширения. Разрешение alarms используется для возобновления связи после остановки фонового процесса расширения.

Обновление распакованного расширения: скачай новый ZIP, закрой браузер, замени файлы в его папке, запусти браузер и нажми «Обновить» на карточке расширения. После обновления приложения нажми «Подготовить расширение» и перезагрузи его карточку в браузере. Файлы в постоянной папке обновятся; сопряжение сохранится.
